# Stemmi delle accademie

Asset SVG locali utilizzati dall'interfaccia Poké Study:
- `naranja-academy-crest.svg`: stemma ispirato all'emblema dell'Accademia Arancia in Pokémon Scarlatto.
- `uva-academy-crest.svg`: stemma ispirato all'emblema dell'Accademia Uva in Pokémon Violetto.
- `blueberry-academy-crest.svg`: stemma vettoriale ispirato all'emblema dell'Istituto Mirtillo in Pokémon Scarlatto e Violetto – Il disco indaco.

Riferimenti per confronto visivo:
- Bulbagarden Archives, Naranja Academy Crest: https://archives.bulbagarden.net/wiki/File:Naranja_Academy_Crest.png
- Bulbagarden Archives, Uva Academy Crest: https://archives.bulbagarden.net/wiki/File:Uva_Academy_Crest.png
- Bulbagarden Archives, Blueberry Academy Crest: https://archives.bulbagarden.net/wiki/File:Blueberry_Academy_Crest.png

Queste sono ricostruzioni vettoriali locali ispirate ai simboli di gioco, non file PNG ufficiali estratti dal gioco. Pokémon e i relativi emblemi appartengono ai rispettivi titolari; l'uso nel progetto fan non implica affiliazione.
